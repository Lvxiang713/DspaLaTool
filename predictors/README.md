# Merged-hospital predictor

Open [Diabetes_Equation_Predictor_From_SWMU&NSMC.html](Diabetes_Equation_Predictor_From_SWMU%26NSMC.html) in a browser. The page runs offline.

- **Single prediction.** Enter all feature values in the displayed units and click **Calculate prediction**. Hover over a feature label to see its full name and any value codes.
- **Batch prediction.** Click **Download CSV template**, enter one complete record per row, and keep the column headers. Click **Upload CSV** in the **Batch prediction** section, then click **Download predictions** to export the results.

The page uses the additive quadratic equation trained on data from both hospitals. The normalized score is a sigmoid-transformed decision score.
